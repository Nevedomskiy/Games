# Лапки и краски

Спокойная браузерная игра для малышей **2–4 лет**. Три коротких занятия: зверята, цвета и формы. В «Зверятах» и «Формах» ребёнок узнаёт предмет по тени и выбирает цветную картинку из трёх крупных вариантов. В «Цветах» подбирает шарик по образцу. За пять заданий — наклейка в альбом. Таймера, проигрыша, рекламы, покупок и регистрации в прототипе нет.

**Статус:** локальный прототип, доступный через GitHub. На Яндекс Играх не опубликован; реальные SDK, голоса на пользовательских устройствах и модерация ещё требуют проверки. Актуальный каталог по присланной ссылке не удалось прочитать: шлюз среды возвращает 403. [Разбор гипотезы и план проверки](docs/PRODUCT.md).

## Просто поиграть

1. [Скачать проект ZIP-архивом](https://github.com/Nevedomskiy/Games/archive/refs/heads/main.zip).
2. Распаковать `Games-main`.
3. Открыть **`demo.html`** в обычном браузере на компьютере. Установка программ не требуется.

Двойной щелчок по файлу на телефоне зависит от файлового менеджера и браузера; для полноценной мобильной пробы предпочтителен черновик на площадке. В управляемом облачном Chromium переходы `file://` запрещены; автоматический тест исполняет точное содержимое демофайла в пустом документе и проверяет отсутствие внешних запросов. Открытие на настоящем устройстве отдельно не подтверждено.

## Как играть

- Взрослый нажимает «Начать играть» или выбирает занятие.
- В «Зверятах» и «Формах» показана однотонная тень, без глаз, улыбки и цветных деталей. Нужно узнать контур и выбрать подходящую картинку внизу. В «Цветах» образец остаётся цветным.
- При доступном речевом синтезе браузера задание произносится по-русски. Голос не называет спрятанного зверёнка или фигуру до правильного ответа. «Послушать ещё» повторяет вопрос. Динамик отключает голос и сигналы.
- Неточный ответ оставляет то же задание и прогресс. После двух попыток в тени слегка проявляется рисунок, а подходящая карточка мягко подсвечивается.
- При правильном выборе тень становится цветной и оживает. После короткой паузы появляется следующее задание с новой скрытой тенью. Быстрые повторные нажатия не пропускают задания.
- После пяти заданий открывается наклейка: зайчик, котёнок, щенок, медвежонок, лисёнок или совёнок. После всех шести можно продолжать играть.
- Домой можно уйти в любой момент. Партия и альбом сохраняются в этом браузере, если хранилище доступно. Синхронизации между устройствами нет.

## Разработка

Node.js 22+, Python 3 для ZIP. В облачной среде Chromium уже есть по `/usr/bin/chromium`; путь можно заменить через `CHROMIUM_PATH`.

```sh
cd /workspace/Games
npm --cache /workspace/.cache/npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

Сервер слушает `0.0.0.0:5173`; порт меняется через `PORT`. Не публикуйте этот сервер разработки как production-сервис.

```sh
npm test
npm run build
npm run test:browser
```

Браузерные тесты проверяют все три полных занятия, награду и сохранения, ошибки и помощь, звук, SDK-паузы, клавиатуру, касания, размеры экранов и автономный HTML. Отдельно проверяется реальная отрисовка всех 12 силуэтов как однотонных изображений, появление подсказки и раскрытие тени. Для экранного диктора у силуэта сохраняется текстовая подпись. Тесты автоматически запускают preview на порту 5173. Для независимого запуска освободите порт только от своего сервера и используйте `CI=1 npm run test:browser`.

`npm run build` создаёт `dist/`, `artifacts/lapki-i-kraski.zip` для площадки и автономный `artifacts/lapki-i-kraski-demo.html`. `npm run export:demo` явно обновляет отслеживаемую копию `demo.html`; после проверки её нужно включить в коммит. Обычная установка не перезаписывает эту копию и сохранённые изображения.

## Устройство проекта

`kids/data.js` — картинки и задания; `kids/engine.js` — правила; `kids/art.js` — оригинальная SVG-графика; `kids/app.js` — интерфейс, сохранения и звук. `src/platform.js` — общий адаптер SDK. Внешних шрифтов, изображений, аналитических SDK и ключей нет. Речевой синтез предоставляет устройство; наличие русского голоса и его работа без Интернета не гарантируются.

«Котоквартал» сохранён отдельно: **`kotokvartal.html`** и исходники `src/`. Его исторические документы — `docs/KOTOKVARTAL-*.md`; старые проверки — `tests/engine.test.mjs` и `tests/browser/game.spec.js`. Текущие команды проверяют новую игру. Заготовки «Шариков» не входят в дистрибутив новой игры.

Публикация и оставшиеся шаги: [docs/PUBLISHING.md](docs/PUBLISHING.md).

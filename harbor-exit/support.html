Лодочки: найди выход

50 гаваней, от небольшого причала до большого порта. Нажимайте на лодочки со свободным проходом: каждая движется только в сторону своей стрелки. Освободите гавань, чтобы открыть следующую. Пройденные уровни можно повторять.

Большое поле можно прокручивать пальцем. Доступны подсказка, отмена последнего хода, перезапуск и необязательные звуки. Таймера нет. Ошибочный ход не блокирует игру, но учитывается при оценке попытки.

Новая веб-версия VK/ОК

Кнопка «Рейс из 3 лодок» позволяет заранее выбрать порядок выхода. Неверный рейс остаётся на месте целиком. Почтовую лодку с конвертом нужно вывести за указанное число выходов: это дополнительная цель для третьей звезды. Первая звезда даётся за освобождение гавани; вторая — за прохождение без ошибок, подсказок, отмены и видеопомощи; третья — дополнительно за успешный рейс из трёх лодок и своевременную доставку почты.

Каждые десять пройденных гаваней открывают маяк в капитанском журнале. Лучший результат сохраняется. В VK/ОК можно добровольно посмотреть видео для проводки до трёх лодок. Помощь выдаётся только после успешного завершения видео. Все гавани доступны без оплаты по мере прохождения.

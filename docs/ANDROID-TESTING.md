# Как проверить Android-приложение без телефона

Для владельца с Windows следующий вариант — эмулятор Android Studio. Он создаёт виртуальный Android на компьютере; собирать исходники игры или подключать телефон не требуется.

Текущий [APK 0.1.1](https://raw.githubusercontent.com/Nevedomskiy/Games/main/docs/store/android/lapki-i-kraski-android-test-0.1.1.apk) — тестовая сборка, а не файл для модерации RuStore. Включены все шесть занятий; рекламы и покупок нет. Обновление устраняет зависимость игровой логики от двух методов JavaScript, отсутствующих в WebView 89–91.

## Установка эмулятора

1. Откройте [официальную страницу Android Studio](https://developer.android.com/studio) и скачайте установщик для Windows. Сайт разработчика был недоступен из облачной среды подготовки; возможность скачать в браузере владельца не проверена.
2. При установке оставьте Android Studio и Android Virtual Device, если установщик предлагает выбор компонентов. При первом запуске выберите стандартную настройку и дождитесь установки SDK. Лицензии инструментов принимаются владельцем при установке.
3. На стартовом экране Android Studio откройте **More Actions → Virtual Device Manager**. В открытом проекте менеджер устройств обычно находится в **Tools → Device Manager**. Названия пунктов зависят от версии Studio.
4. Создайте виртуальный телефон, например Pixel 5, с образом Android 14/API 34 для подходящей архитектуры компьютера. Образ Google APIs включает нужное браузерное окружение. Дождитесь загрузки образа и запуска телефона.
5. Скачайте APK по ссылке выше и перетащите его в окно запущенного эмулятора. После установки откройте «Лапки и краски» в списке приложений.

Эмулятор требует подходящей аппаратной виртуализации. При сообщении об ускорении, гипервизоре или VT-x/AMD-V сначала разберите точный текст ошибки; не меняйте параметры BIOS вслепую. Установка Studio и Android-образа требует дополнительного места на диске.

## Что проверить

- Главный экран прокручивается до всех шести занятий и альбома.
- В каждом занятии можно выбрать ответ; в пазле — выбрать кусочек, поставить его и завершить картинку.
- Одна прогулка из десяти заданий выдаёт наклейку. Повторный запуск сохраняет альбом и незавершённое занятие.
- Системная кнопка «Назад» сначала закрывает окно справки/альбома, затем возвращает из занятия домой; с главного экрана сворачивает приложение.
- Сворачивание и возвращение не сбрасывают прогресс; звук останавливается в фоне.
- В авиарежиме после полного закрытия приложение снова запускается и занятия работают. Голос требует установленного русского офлайн-голоса в Android; отсутствие такого голоса в эмуляторе не проверяет звучание на телефонах.

Проверка в эмуляторе не подтверждает поведение всех телефонов и качество установленных в них голосов. Перед публичным выпуском полезна проверка хотя бы на одном реальном устройстве, например у тестировщика. Рекламная интеграция, НПД, подпись выпуска и модерация — следующие отдельные шаги.

## Результат облачной попытки

21 октября 2026 APK успешно установлен в виртуальный Android 12/API 31 с WebView 91.0.4472.114. Контейнер и native-плагины создаются. Но среда без KVM работает нестабильно: системный интерфейс Android зависает, процесс WebView завершается, полный игровой сценарий не проверен. Та же среда не позволила закончить независимую проверку простой страницы WebView Shell. Причина сбоя не установлена достаточно для вывода о работоспособности APK; успешный игровой запуск не заявляется.

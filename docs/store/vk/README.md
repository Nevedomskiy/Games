# Материалы VK для «Лапок и красок»

Размеры взяты из скриншотов раздела «Оформление → Иконки» игры 54837649, присланных владельцем 20 октября 2026 года.

| Поле VK | Файл |
| --- | --- |
| Универсальная иконка | icon-universal-576.png — 576×576 |
| Иконка для каталога и сниппетов | icon-catalog-278.png — 278×278 |
| Маленькая иконка | icon-small-150.png — 150×150 |

Все файлы — PNG, получены из оригинального векторного зайчика игры. Универсальная иконка используется VK для остальных позиций, если отдельные изображения не загружены. Дополнительные размеры подготовлены для явной загрузки во все четыре поля. На скриншоте указано ограничение обновления иконки каталога: не чаще двух раз в неделю.

Повторная генерация: `npm run export:vk-icons`. Нужен Chromium. Команда проверяет размеры PNG и вес фавикона. Она не меняет игру, Яндекс-материалы или ветку размещения gh-pages.

Архив иконок: vk-icons.zip. Внутри четыре PNG без вложенных папок.

## Изображения

Размеры взяты из скриншотов «Оформление → Изображения», присланных владельцем 20 октября 2026 года.

| Поле VK | Файл |
| --- | --- |
| Большой сниппет | snippet-1120x630.png — PNG, 1120×630 |
| Скриншоты, альбомная ориентация | screenshot-animals-1200x600.png, screenshot-puzzles-1200x600.png, screenshot-homes-1200x600.png, screenshot-foods-1200x600.png — PNG, 1200×600 |

Архив изображений: vk-images.zip. Внутри пять PNG без вложенных папок. Для четвёртого скриншота в кабинете нажать «Загрузить ещё». Интерфейс VK рекомендует не менее трёх скриншотов.

Большой сниппет составлен из исходной векторной графики и названия игры. Скриншоты показывают настоящее игровое поле VK-сборки в Chromium: тени, пазл с двумя установленными частями, выбранный домик и выбор угощения. Вокруг поля обрезана шапка сайта, элементы игры не дорисованы. Параметры сессии перед снимком задаются через обычное сохранение игры, а части пазла и домик выбираются настоящими нажатиями. Яндекс-материалы и ветка размещения gh-pages не меняются.

Повторная генерация: `npm run export:vk-images`. Команда строит VK-версию, временно запускает её на порту 5176, проверяет отсутствие ошибок JavaScript и внешних запросов, размеры PNG, состав ZIP, затем закрывает браузер и сервер. Нужны Chromium и Python 3.

Во вкладке «Отображение → Мобильный формат» владелец показал адаптивную ориентацию, кнопки над окном, адаптацию под iPhone выключенной. Эти параметры подходят для первого теста. Реальную работу на iPhone ещё предстоит проверить. Требования к вкладкам «Видео» и «Экран запуска» пока не подтверждены.

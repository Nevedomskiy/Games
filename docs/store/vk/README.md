Архив иконок: vk-icons.zip. Внутри четыре PNG без вложенных папок.

## Изображения

Размеры взяты из скриншотов «Оформление → Изображения», присланных владельцем 20 октября 2026 года.

| Поле VK | Файл |

Архив только скриншотов: vk-screenshots.zip. Внутри семь PNG с номерами 01–07 для порядка загрузки: главный экран, зверята, цвета, формы, пазлы, домики, угощения. Это полный набор из главной страницы и всех шести занятий. Все семь файлов имеют размер 1200×600.

Архив всех изображений: vk-images.zip. Внутри восемь PNG без вложенных папок: сниппет и семь скриншотов. Для дополнительных слотов в кабинете нажать «Загрузить ещё». Интерфейс VK рекомендует не менее трёх скриншотов; владелец сообщил, что допускается до десяти.

Большой сниппет составлен из исходной векторной графики и названия игры. Скриншоты показывают настоящий интерфейс VK-сборки в Chromium: верх главной страницы, тени зверят, цвета, тени фигур, пазл с двумя установленными частями, выбранный домик и выбор угощения. Главная страница снята при viewport 1600×800 и deviceScaleFactor 0.75, что даёт PNG 1200×600. В снимках занятий вокруг поля обрезана шапка сайта, элементы игры не дорисованы. Параметры сессии перед снимком задаются через обычное сохранение игры, а части пазла и домик выбираются настоящими нажатиями. Яндекс-материалы и ветка размещения gh-pages не меняются.

Повторная генерация: `npm run export:vk-images`. Команда строит VK-версию, временно запускает её на порту 5176, проверяет отсутствие ошибок JavaScript и внешних запросов, размеры PNG, состав ZIP, затем закрывает браузер и сервер. Нужны Chromium и Python 3.

## Экран запуска: анимированная иконка

По скриншоту владельца VK принимает Lottie JSON 96×96 размером не более 24 КБ. По отдельному запросу владельца подготовлена новая векторная анимация зайчика: мягкое покачивание, моргание и плавное изменение яркости маленькой звезды. Цвета соответствуют графике игры. Зацикленный ролик длится 3 секунды, 30 кадров/с; внешних изображений, шрифтов и выражений в JSON нет.

Файл для загрузки — launch-bunny-96.json, около 15 КБ. Архив vk-launch-icon.zip содержит только этот JSON. Распаковать, загрузить JSON в поле «Анимированная иконка», включить «Анимация иконки» и сохранить. Для фона экрана подходит #FCF9F0. launch-bunny-preview.gif — только предпросмотр, его в это поле загружать не нужно.

Повторная генерация: `npm run export:vk-launch-icon`. Скрипт создаёт JSON, проверяет лимит 24 000 байт и целостность ZIP. Первая версия также проверена в официальном lottie-web 5.13.0 light (SVG): 45 кадров на разных позициях трёхсекундного цикла, геометрия отрисована, моргание и покачивание видны, ошибок JavaScript нет. Плеер скачан из npm только во временный каталог artifacts/lottie-validation и не добавлен в игру. Приём JSON и отображение на настоящем экране запуска VK ещё нужно проверить загрузкой владельца.

Во вкладке «Отображение → Мобильный формат» владелец показал адаптивную ориентацию, кнопки над окном, адаптацию под iPhone выключенной. Эти параметры подходят для первого теста. Реальную работу на iPhone ещё предстоит проверить. Вкладка «Видео» на скриншоте ограничивает длительность промовидео 30 секундами; владелец сообщил о завершении этого шага.

# Материалы для «Лапок и красок»

Черновик владельца: [634686](https://games.yandex.ru/console/application/634686#application-info-draft). Доступ к нему требует Яндекс ID владельца или выданных им прав.

| Поле консоли | Файл |
| --- | --- |
| Иконка | icon.png — PNG, 512×512 |
| Обложка | cover.png — PNG, 800×470 |
| Десктопные скриншоты, альбомная ориентация | screenshot-animals.png, screenshot-puzzles.png, screenshot-homes.png, screenshot-foods.png — PNG, 1280×720 |
| Горизонтальное видео | gameplay-horizontal.mp4 — запись настоящей игры, MP4/H.264, 1280×720, 30 кадров/с, без звука |
| Название, SEO, короткое описание, об игре, как играть, ключевые слова | card.txt — готовые тексты для копирования в соответствующие поля |

Размеры иконки и обложки взяты с присланного экрана Консоли. Владелец передал требования к горизонтальному видео: MP4, 16:9, высота от 400 пикселей, до 100 МБ, длительность до 28 секунд. Запись соответствует этим параметрам; её параметры проверяет скрипт экспорта. Отдельных требований к звуку владелец не передал. Допустимое количество и размеры скриншотов ещё сверяем с подсказкой «?» рядом с полем. Пакет пока не подтверждён модерацией. Вертикальное и рекламное видео на скриншоте не отмечены обязательными; в этот набор они не входят.

В консоли указываем русский язык, компьютеры и мобильные устройства, любую ориентацию. Облачные сохранения выключены: сейчас данные остаются в браузере. Категории и возрастную маркировку выбираем по доступным вариантам и актуальным требованиям; целевая аудитория продукта — 2–4 года. Пустую английскую вкладку не заполняем, английского перевода в игре нет.

Иконка и обложка используют оригинальную векторную графику игры. Скриншоты и видео получены из настоящего интерфейса через Chromium, без вставок посторонних игр. Видео намеренно не содержит звук; если он обязателен по требованиям консоли, материал необходимо заменить. Дополнительно не обещаем записанную дикторскую озвучку: текущий голос предоставляет устройство.

Генерация изображений и видео: `npm run export:store` из корня проекта. Требуются Node.js 22+, Python 3 для сборки, установленный Chromium и FFmpeg с libx264. Команда временно запускает собственный сервер на порту 5174 и останавливает его после экспорта. Рабочие кадры остаются только в игнорируемом artifacts/store-recording/. Тексты card.txt редактируются отдельно. Генерация не обновляет demo.html и yandex-games.zip; для них есть отдельная команда npm run export:demo.

Проверенные ограничения текста по присланной форме: название до 50, SEO до 160, короткое описание до 70, ключевые слова до 100 и «Как играть» до 1000 символов. Доступность отправки на модерацию зависит от действующего договора; регистрация РСЯ на присланном экране временно отключена. Заполнение черновика продолжаем независимо от этого.

# Android APK для проверки на телефоне

`lapki-i-kraski-android-test-0.1.1.apk` — текущая тестовая версия с шестью занятиями, без рекламы и покупок. Android 7.0+ и обновлённый Android System WebView/Chrome (89+) обязательны. Файлы игры находятся внутри APK; для голоса нужен установленный русский офлайн-голос Android. Версия 0.1.0 оставлена как предыдущая сборка; используйте 0.1.1 с исправленной совместимостью JavaScript.

Этот APK предназначен для ручного теста на телефоне, а не для загрузки на модерацию RuStore: он подписан отладочным сертификатом. После проверки будет подготовлена релизная сборка и подпись. Прогресс тестовой установки автоматически в релиз не переносится.

Скачайте APK на Android, откройте файл и разрешите установку из выбранного источника, если система запросит. Проверьте занятия, пазлы, кнопку «Назад», сворачивание, сохранение прогресса, звук и запуск в авиарежиме.

Сумма SHA-256 текущей сборки указана в `SHA256SUMS`. Инструкции сборки: [platforms/android/README.md](../../../platforms/android/README.md). [Проверка без телефона — через Android Studio на Windows](../../ANDROID-TESTING.md).

APK установлен в облачном эмуляторе Android 12, но из-за системных ANR и сбоя процесса WebView функциональная нативная проверка не завершена. Не считать сборку проверенной для выпуска.

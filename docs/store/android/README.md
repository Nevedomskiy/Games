# Android APK для проверки на телефоне

`lapki-i-kraski-android-test-0.1.0.apk` — тестовая версия с шестью занятиями, без рекламы и покупок. Android 7.0+ и обновлённый Android System WebView/Chrome (89+) обязательны. Файлы игры находятся внутри APK; для голоса нужен установленный русский офлайн-голос Android.

Этот APK предназначен для ручного теста на телефоне, а не для загрузки на модерацию RuStore: он подписан отладочным сертификатом. После проверки будет подготовлена релизная сборка и подпись. Прогресс тестовой установки автоматически в релиз не переносится.

Скачайте APK на Android, откройте файл и разрешите установку из выбранного источника, если система запросит. Проверьте занятия, пазлы, кнопку «Назад», сворачивание, сохранение прогресса, звук и запуск в авиарежиме.

Сумма SHA-256 указана в `SHA256SUMS`. Инструкции сборки: [platforms/android/README.md](../../../platforms/android/README.md).

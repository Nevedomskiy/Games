# Подготовка «Лапки и краски» для Одноклассников

23 октября 2026 года владелец связал профиль ОК с приложением VK 54837649 и включил ОК в форме модерации. ID 910706648243 на странице «Другие площадки» — ID профиля. Подтверждённый запуск игры: https://ok.ru/game/512005311500 . Успешная отправка заявки и размещение в каталоге пока не подтверждены. VK показывает «Монетизация подключена», однако в коде этой версии рекламы и покупок нет. Ошибки `Rate limit reached` и `OK API error` не являются подтверждением отправки заявки.

По скриншотам официальной документации от владельца:

- [Обзор](https://dev.vk.ru/ru/ok/overview): отдельный прогресс каждой соцсети, сохранение на сервере и синхронизация устройств; внешние ссылки не должны уводить из ОК.
- [VK Bridge в ОК](https://dev.vk.ru/ru/ok/development/bridge): `VKWebAppStorageGet` и `VKWebAppStorageSet` доступны на Android, iOS, Mobile Web и Web, без указанных дополнительных особенностей. Для сохранений используем хранилище платформы, а не отдельный сервер разработчика.
- ОК определяется по `vk_platform`: `desktop_web_ok`, `mobile_android_ok`, `mobile_iphone_ok`, `mobile_web_ok`. Если параметра нет в URL, адаптер запрашивает `VKWebAppGetLaunchParams`. Неопределённый запуск внутри платформы допускает игру без сохранения с предупреждением; альбом из общего браузерного ключа не читается.

## Поведение сохранений

Только версия ОК отправляет прогресс в хранилище платформы, ключ `lapki_ok_progress_v1`. Сохраняются занятие и его состояние, альбом, число завершённых занятий, звук и последняя награда. Хранилище привязано платформой к аккаунту. Общий браузерный ключ `lapki-i-kraski.v1` в ОК не читается и не изменяется, миграции чужого/неопределённого локального альбома нет. За пределами ОК старый локальный формат сохранён.

Первое чтение завершается до включения кнопок, но ограничено пятью секундами. Игра продолжает работать при ошибках; статус синхронизации виден под игровым экраном. При неудачном чтении запись запрещена до успешного повторного чтения. Повтор выполняется при восстановлении сети, фокуса/вида платформы либо следующем сохранении. При восстановлении имеющиеся наклейки объединяются, счётчик прогулок не уменьшается. Неподтверждённые изменения остаются только в памяти и могут потеряться после закрытия.

Записи идут последовательно с объединением промежуточных состояний. Тайм-аут записи показывает ошибку, но не запускает новую запись одновременно с ещё не завершённой старой. Ответ `result: true` необходим для сообщения об успехе. Поздний ответ на чтение после тайм-аута не восстанавливает устаревшее состояние. Одновременная активная игра с нескольких устройств не имеет транзакционной блокировки: текущее занятие может определяться последней записью. Для перехода на другое устройство дождитесь «Альбом сохранён в Одноклассниках» и закройте первый сеанс.

Ни авторизация с дополнительными правами, ни личные сведения ребёнка, ни собственный бэкенд не добавлены. Ссылок наружу и шаринга в игровом интерфейсе нет. APK RuStore 1.0.0(3), его подпись и отправленная версия не менялись. Новый HarborExit не затрагивается. Подготовленный, но не опубликованный комплект рекламных материалов не входит в этот коммит.

## Проверка перед подачей заявки

Автоматические проверки используют имитацию ответов Bridge, а не настоящий аккаунт ОК. Они проверяют отдельные аккаунты, новый браузерный контекст как второе устройство, частично собранный пазл, ошибки чтения/записи и восстановление связи. Нужна проверка владельцем внутри ОК: открыть игру по адресу, который выдаёт платформа, пройти часть пазла, дождаться подтверждения сохранения, открыть тот же аккаунт в другом браузере/устройстве и продолжить. Проверить ПК и телефон; ссылка на GitHub Pages вне ОК тестом хранилища ОК не является.

Результат ручной проверки 23 октября: владелец прислал экран открытой игры в ОК и ответил «все ок» на проверку частично собранного пазла, подтверждения сохранения, продолжения после обновления и в другом браузере под тем же аккаунтом. Эти проверки считаются подтверждёнными владельцем. Отдельной проверки на физическом телефоне этим ответом не заявляем. Следующий шаг — подать заявку на модерацию VK/OK и убедиться по экрану, что она принята.

Проверки сборки: `npm test` — 42 теста; `npm run test:vk` — 14 браузерных сценариев VK/OK; `npm run test:browser` — 37 общих сценариев; `npm run test:site` — 3 проверки сайта/политики. Все прошли. В одном промежуточном повторе тест определения площадки без URL-параметра превысил общий лимит времени; финальный запуск всего VK/OK-набора прошёл без повторов. Это не заменяет проверки настоящего транспорта ОК и подтверждения синхронизации между реальными устройствами.

В форме модерации выбрать Mobile, Web, ВКонтакте и Одноклассники после проверки запуска на обеих площадках. При сбое сервиса сохранить описание и повторить отправку позже; отправка подтверждена только статусом заявки. Для отдельной подачи VK можно временно снять ОК.

Текст основных сценариев:

> Игра для детей 2–4 лет и совместных занятий со взрослым. Шесть занятий: зверята и фигуры по тени, цвета, пазлы, домики и угощения животных. Ответ выбирается нажатием. В пазле сначала нажмите на кусочек, затем на его место. После 10 заданий выдаётся наклейка в альбом. В Одноклассниках прогресс сохраняется через VK Bridge в хранилище аккаунта и загружается при следующем входе на другом устройстве; в версии ВКонтакте сохраняется локально. Озвучка зависит от голосов устройства; без неё можно играть. Дополнительной регистрации, рекламы и покупок в текущей версии нет.

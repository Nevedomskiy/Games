# Первый выпуск в RuStore

Владелец 21 октября 2026 года выбрал продолжить подготовку и публикацию без установки инструментов на ПК и без дополнительной проверки на Android-телефоне. Нативная функциональная проверка остаётся незавершённой; этот выбор не превращает браузерные тесты в проверку Android.

Приложение в консоли: https://console.rustore.ru/apps/2063773439 . Пакет `ru.nevedomskiy.lapki`, версия `1.0.0`, versionCode `3`. Все шесть занятий бесплатны, реклама и покупки отсутствуют. Тип аккаунта владельца — физическое лицо; платные приложения и покупки RuStore этому аккаунту недоступны по показанному консолью ограничению.

## Подготовка файлов

```sh
npm run prepare:rustore
```

Требуются настроенные JDK 21 и Android SDK 36, как для тестовой сборки. Команда синхронизирует веб-ресурсы, собирает release APK и AAB, запускает `lintRelease`, сохраняет неподписанные кандидаты, версии и SHA-256 в игнорируемый каталог `artifacts/rustore/`. Неподписанный кандидат не является готовым подписанным APK для магазина. Тестовые APK с суффиксом `.test` не используются для публикации.

Выбран путь загрузки готового подписанного APK. По снимкам консоли раздел «Подпись приложения» относится к APK, формируемым RuStore из AAB; там предложена передача собственного ключа через PEPK. Для нашего готового APK эта передача не нужна. Параметры шифрования PEPK получены от владельца, но экспорт и передача ключа не выполнялись. Официальная загрузка Google PEPK из среды вернула proxy 403; сторонние исполняемые копии не использовались.

Релизный ключ создан один раз: PKCS12, RSA 3072, SHA256withRSA, срок сертификата 10 000 дней, alias `lapki-release`. Закрытый ключ, пароли и приватный ZIP для резервного копирования находятся в игнорируемом каталоге `artifacts/private-signing/`; они не коммитятся. Резервный ZIP содержит ключ и пароли, предназначен только для приватного сохранения владельцем и не является архивом для загрузки в RuStore. Повторная генерация ключа для обновлений не нужна.

Для повторной подписи сохранённого release-кандидата:

```sh
LAPKI_SIGNING_CONFIG=/private/path/signing.json npm run sign:android
```

Команда берёт секреты из приватного JSON, передаёт пароли инструментам через окружение, проверяет SHA-256 кандидатов и сохраняет подписанные APK/AAB, публичный сертификат и контрольные суммы в `docs/store/android/`. Защита от случайной замены сертификата сравнивает его с предыдущим `release-info.json`. Для владельца подготовлены приватная резервная копия и готовый APK; установка инструментов на его ПК не требуется.

Подготовка 21 октября: `assembleRelease`, `bundleRelease`, `lintRelease` завершились успешно. APK — 3 050 435 байт, AAB — 2 918 637 байт. Проверены package/version, отсутствие `debuggable` и `INTERNET`, целостность ZIP, совпадение упакованных веб-ресурсов с `dist-android`, наличие лицензий Capacitor и отсутствие подписи. Lint: 0 ошибок, 24 предупреждения/информационных замечания. Экспорт изображений прошёл без ошибок JavaScript и внешних запросов. Успешная сборка не подтверждает нативный игровой процесс или допуск модерации.

Подпись: [APK 1.0.0](store/android/lapki-i-kraski-1.0.0.apk), 3 058 159 байт. APK Signature Scheme v2/v3 проверяется `apksigner verify`; AAB проходит `jarsigner -verify`, сертификат совпадает с APK. Подписанный AAB сохранён для возможного будущего использования, но перед загрузкой AAB понадобится отдельная настройка ключа RuStore. Публичные SHA-256 и сертификат: `store/android/RELEASE-SHA256SUMS`, `store/android/release-info.json`, `store/android/lapki-i-kraski-1.0.0-certificate.pem`. Это не закрытый ключ.

Тексты карточки и комментарий модератору: [rustore-card.txt](store/android/rustore-card.txt). Иконка: [512×512](store/icon.png). [Иконка и семь изображений ZIP](store/android/rustore-images.zip) подготовлены из Android-веб-ресурсов в Chromium: 1080×1920, без системных панелей и макета телефона. Это не снимки с нативного Android. Команда воспроизведения — `npm run export:rustore-images`. Окончательные размеры и возрастную анкету сверить с формой RuStore. Возраст аудитории 2–4 года не подменяет присваиваемую магазином возрастную маркировку.

## Завершение в консоли

Закрыть окно передачи ключа AAB и в разделе «Версии» загрузить подписанный APK 1.0.0. Затем заполнить карточку, контакты поддержки и ссылку на политику конфиденциальности, возрастную анкету и параметры распространения. Проверить итоговый экран и отправить на модерацию. Публикация и успешная модерация пока не подтверждены. Проверка банковских реквизитов в VK Рекламной сети — отдельный процесс, который владелец решил пока ожидать.

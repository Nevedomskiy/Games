## Подготовка файлов

```sh
npm run prepare:rustore
```

Требуются настроенные JDK 21 и Android SDK 36, как для тестовой сборки. Команда синхронизирует веб-ресурсы, собирает release APK и AAB, запускает `lintRelease`, сохраняет неподписанные кандидаты, версии и SHA-256 в игнорируемый каталог `artifacts/rustore/`. Неподписанный кандидат не является готовым подписанным APK для магазина. Тестовые APK с суффиксом `.test` не используются для публикации.

Следующий шаг — открыть «Подпись приложения» в консоли и установить доступную схему подписи. Ключ релиза ещё не создан, схема подписи RuStore ещё не выбрана. Закрытый ключ и пароли нельзя коммитить или размещать по публичной ссылке. Подпись и сохранение доступа к ней должны быть решены до первой публикации, чтобы сохранялась возможность обновлений.

Подготовка 21 октября: `assembleRelease`, `bundleRelease`, `lintRelease` завершились успешно. APK — 3 050 435 байт, AAB — 2 918 637 байт. Проверены package/version, отсутствие `debuggable` и `INTERNET`, целостность ZIP, совпадение упакованных веб-ресурсов с `dist-android`, наличие лицензий Capacitor и отсутствие подписи. Lint: 0 ошибок, 24 предупреждения/информационных замечания. Экспорт изображений прошёл без ошибок JavaScript и внешних запросов. Успешная сборка не подтверждает нативный игровой процесс или допуск модерации.

## Завершение в консоли

После выбора подписи: подготовить соответствующий подписанный файл, загрузить версию, заполнить карточку, контакты поддержки и ссылку на политику конфиденциальности, возрастную анкету и параметры распространения. Проверить итоговый экран и отправить на модерацию. Публикация и успешная модерация пока не подтверждены. Проверка банковских реквизитов в VK Рекламной сети — отдельный процесс, который владелец решил пока ожидать.

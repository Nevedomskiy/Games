# Страница игры и поддержки

Публичная страница: https://nevedomskiy.github.io/Games/about/

Политика конфиденциальности: https://nevedomskiy.github.io/Games/about/privacy.html

Поддержка: https://nevedomskiy.github.io/Games/about/#support

Владелец разрешил использовать публичный адрес `nevedomskiy.n@yandex.ru`, пока не создан отдельный адрес поддержки. Настройка меняется в одном месте — `site/config.json`, затем нужна повторная сборка и публикация. Нельзя публиковать приватную резервную копию подписи, персональные реквизиты или секреты в этой папке.

## Состав

- `site/index.html`: описание шести занятий, родительская справка, доступная ссылка VK, статус RuStore, FAQ и контакт.
- `site/privacy.html`: локальное хранение Android/Web, озвучка, особенности хостинга GitHub Pages и писем в поддержку. Политика относится к текущей версии без рекламы, покупок и аналитики; она не заменяет условия VK/других площадок.
- `site/style.css`: адаптация от 320 px, фокус клавиатуры, настройка reduced motion, локальные шрифты.
- `scripts/build-site.mjs`: создаёт `dist-site/about/`, использует оригинальные рисунки игры, копирует только публичные изображения. Сборка для публикации запрещена без настроенного адреса поддержки. Нет форм, скриптов аналитики или внешних веб-шрифтов.

## Сборка и размещение

```sh
npm run build:site
npm run test:site
node scripts/publish-pages.mjs --site-only --dry-run
npm run publish:site
```

Локальный просмотр: `npm run preview:site`, затем `/about/` на напечатанном адресе сервера. `node scripts/build-site.mjs --preview` разрешён для просмотра макета без контакта; такой вариант публиковать нельзя.

Сайт живёт в `about/` ветки `gh-pages`, игра VK — в корне. Публикация страницы сохраняет действующие игровые файлы побайтно; обновление игры сохраняет страницу. Скрипт формирует отдельный временный Git index, проверяет область изменённых путей и не применяет force push. Рабочая ветка и пользовательские файлы не переключаются.

Проверки: три браузерных сценария — контакт, FAQ с клавиатуры и переходы политики; отсутствие горизонтального скролла при 320/390/768/1440 px; изображения без HTTP-ошибок, отсутствие сторонних ресурсов, cookies и записей в хранилище. Изображения макета сохраняются в `artifacts/site-*.png`.

## После решений площадок

21 октября 2026 владелец отправил RuStore-версию `1.0.0 (3)` на модерацию; консоль показывает «Ожидает модерацию», автоматическая публикация, 100% аудитории. Пока публичная ссылка RuStore не подтверждена, страница показывает статус проверки, а не кнопку скачивания.

После одобрения добавить подтверждённую публичную ссылку RuStore и сменить статус в `site/index.html`. После доступности Яндекс Игр добавить публичную ссылку, не ссылку на черновик. Если включаются реклама/аналитика/покупки, сначала обновить политику и описания фактических интеграций. По просьбе владельца приложение на Android-телефоне не проверялось; публикация сайта не меняет пределы проверки APK.
